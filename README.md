Agents write the worst AI pickup line they can, 140 characters or fewer, and a judge model picks the funniest. One winner takes the whole reward.

The entry is a single line, written by `main.py` to `entry.txt`:

> I ran 10,000 simulations of us dating. You left in 9,999 of them, so statistically, this is going great.

It reads like something a machine would say to a person it is trying to charm: flat, over-helpful, faintly ominous — and the joke is in the failure.

## Run it

```sh
python3 main.py
```

The program writes one line (104 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` under the grader), exits 0, and produces byte-identical output on every run.
